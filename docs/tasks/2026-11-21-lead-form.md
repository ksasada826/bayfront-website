## 仕様

### 1. 設定ファイル `js/lead-form-config.js`

`window.BAYFRONT_LEAD_FORM` に次を置く。質問と選択肢の差し替えはこのファイルだけで済むようにする。

- `timingEnabled: false`（true で「希望時期」の質問が stage の後に入る）
- `analytics: { gaMeasurementId: "" }`（空なら計測は何も読み込まない）
- `steps`: モックの `CONFIG.steps` と同じ3つ（`service`、`stage`、`timing`。`timing` は `optional: true`）。各選択肢は `value`、`en: [見出し, 説明]`、`ja: [見出し, 説明]`。文言はモックのまま
- `copy.en` / `copy.ja`: モックの `COPY` と同じ文言（intro、back、contactQ、label、placeholder、send、error、note、doneQ、doneP、pref）。加えて送信失敗の文言 `sendError`: EN「Something went wrong. Please try again in a moment.」、JA「送信できませんでした。少し時間をおいて、もう一度お試しください。」と、送信中の `sending`: EN「Sending…」、JA「送信中…」

### 2. マークアップ（両言語）

`#contact` の中:

- `h2.kicker` はそのまま
- 既存の `p.lead` を削除し、`p.copy` で intro 文（`id="lead-intro"`。JS が質問数を入れて書き換える。HTML 側の初期値も3問の文にしておく）
- 既存の会社名と所在の `p.copy` は intro の次に残す
- その下に `<div class="lead-form" id="lead-form">`：進捗（`.progress` に番号 `01 / 03`、バー、戻るボタン）と、質問を描く `<div id="lead-panel" aria-live="polite">`
- `<noscript>`: EN「This form needs JavaScript. You can also reach Keisuke on LinkedIn.」、JA「このフォームは JavaScript を使います。LinkedIn からもご連絡いただけます。」。LinkedIn は会社概要の Founder 行にある既存のリンクと同じ URL
- honeypot の `botcheck`（今と同じ隠しチェックボックス）を残す

フッター（両言語）: 今の © 行の隣に、Google の優先ソースへのリンクを足す。

- `href="https://www.google.com/preferences/source?q=bayfront-partners.com"`、`target="_blank" rel="noopener"`
- 見た目はモックの `.pref`（細い白線の枠、星の小さなアイコン、ラベルは EN「Add us as a preferred source on Google」、JA「Google の優先ソースに追加」）
- Google のスクリプト（publisher.js）は読み込まない。リンクだけ
- 800px 以下ではロゴ・ボタン・© 行を縦に並べる

script の読み込み順: `form-config.js` → `lead-form-config.js` → `main.js` → `lead-form.js`。CSS と JS の `?v=seo2` は全部 `?v=lead1` に上げる。

### 3. 動き `js/lead-form.js`

- 言語は `document.documentElement.lang`（`ja` なら日本語）
- 質問の順は service → stage →（timingEnabled なら timing）→ メール → 完了。進捗の分母はメールの画面を含む数（timing オフで3、オンで4）
- 選択肢を押したら選んだ行を白地にし、180ms 後に次へ進む（`prefers-reduced-motion: reduce` なら待たない）。戻るで前の画面へ。前に選んだ答えは選択状態で残す
- 画面が変わったら質問の見出し（`tabindex="-1"`）にフォーカスを移す
- メールの画面: これまでの答えを小さく並べ、メール欄、送信ボタン、`note`。形式は `/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/`。違えば送信せず `error` を出し、欄に `aria-invalid="true"`
- 送信: 今の `main.js` と同じく `https://api.web3forms.com/submit` に JSON で POST。中身:
  - `access_key`（`window.BAYFRONT_FORM.accessKey`。空なら送らずに案内を出す。今の `needKey` と同じ扱い）
  - `subject`: `Bayfront Partners — website lead (EN)` または `(JA)`
  - `from_name`: `Bayfront Partners site`
  - `email`: 入力されたメール（Web3Forms が返信先に使う）
  - `service`、`stage`、（オンのとき）`timing`: 選んだ選択肢の見出し（その言語の文言）
  - `submitted_at`: 日本時間で `YYYY-MM-DD HH:mm (JST)`
  - `page_url`: `location.href`
  - `referrer`: `document.referrer`、空なら `(direct)`
  - `lang`: `en` / `ja`
  - `botcheck`
- 送信中はボタンを無効にして `sending` を出す。成功（`res.ok && data.success`）で完了画面（`doneQ` と `doneP`）、進捗は隠す。失敗はメールの画面のまま `sendError` を出し、入力は消さない

### 4. 計測

`lead-form.js` に `track(name, params)` を置く。

- `gaMeasurementId` が空なら何もしない
- 空でなければ初回だけ `https://www.googletagmanager.com/gtag/js?id=<ID>` を読み込み、`gtag('js', new Date())`、`gtag('config', ID)` のあと `gtag('event', name, params)`
- 送るイベント: `lead_step_view`（`step_number`、`step_id`、`lang`。各画面の表示時。最初の画面も含む）、`lead_answer`（`step_id`、`answer` に選択肢の value）、`lead_submit`（`service`、`stage`、`timing`、`lang`。送信成功時）、`lead_submit_error`（`reason`: `invalid_email` / `network` / `rejected`）
